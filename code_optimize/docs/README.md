# Documentation

This directory holds the longer design and maintenance notes. Short directory
orientation is kept next to the code it describes.

## Tree

```text
docs/
├── ARCHITECTURE.md       model and recurrent schedule details
├── DECISIONS.md          implementation decisions and trade-offs
├── REFACTOR_PLAN.md      refactor scope and ownership changes
├── COMPLETION_AUDIT.md   requirement and verification audit
└── TROUBLESHOOTING.md    known runtime and dependency issues
```

Use `add_system/*/README.md` for a file-level map and these documents for
cross-cutting behavior, historical decisions, and failure diagnosis.
